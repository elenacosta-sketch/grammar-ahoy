# Grammar Ahoy! — GitHub-ready website

## Upload and publish

1. Extract this ZIP.
2. Create a GitHub repository.
3. Select Add file → Upload files.
4. Upload the CONTENTS of this grammar-ahoy folder, including the worksheets folder. Keep index.html at the repository root.
5. Commit the files.
6. Open Settings → Pages, choose Deploy from a branch, select main and / (root), then Save.
7. Wait for GitHub to display the website link.

No installation or build step is needed. GitHub does not extract ZIPs automatically.

## Features

- 36 grammar categories and 288 base questions from the supplied worksheets.
- 2–6 teams, with editable team names and up to four player names each.
- Colourful 4×4 mission board with automatic scoring.
- Multiple-choice, written-answer and sentence-building activities.
- Replay rounds with unseen questions first and optional cumulative scores. A category’s question pool repeats after all its questions have been used.
- Teacher controls and CSV score export.

Scores and student names are saved in the current browser only. Teacher controls have no password. GitHub Pages does not inherit the original Sites publication’s private access settings.
